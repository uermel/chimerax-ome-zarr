Command: open

Usage: open ( filename.zarr | ngff:[protocol:]URL.zarr ) [ scales scale1,scale2,... ] [ labels true|false ] [ readAhead N ]

OME-Zarr files can be opened with the open-command similar to any other ChimeraX-supported file. When appending the "ngff:"-prefix to the URL and including a protocol prefix (such as "s3://" or "smb://") allow loading Zarr files from remote storage. OME-Zarr 0.4/Zarr v2 and OME-Zarr 0.5/Zarr v3 images are detected automatically. YX/ZYX images may include leading time and channel axes. Bioformats2raw layout 3 roots are resolved automatically, and all declared or consecutively numbered image series are opened. When no scales are specified, this command creates lazily loaded multiscale Volumes and chooses a compatible resolution from the "step" setting of the volume command or Volume Viewer. When scales are specified, each selected level is opened independently, including its time/channel hierarchy and physical origin.
Associated OME-Zarr labels are opened automatically but hidden. Their integer index maps work with the segmentation surfaces and segmentation colors commands. Nonzero label values declared in image-label colors or properties metadata are also registered as editable models in ChimeraX's Segmentations tool. Set labels false to skip associated-label discovery.
For 3D time series, temporal read-ahead preserves the current region, sampling step, channel, and resolution level. If readAhead is omitted, an adaptive memory-bounded buffer is filled after the current frame is drawn. Set readAhead to a nonnegative number to limit the number of future timepoints, or 0 to disable it. Read-ahead is best-effort and does not delay the built-in Map Series player. Plane display does not trigger temporal reads.
Editing an imported mask updates the in-session label map but does not write to the OME-Zarr store.

Examples:

open /path/to/image.zarr - open a local OME-Zarr
open ngff:s3://bucket/path/to/image.zarr - open an OME-Zarr from AWS S3
open ngff:s3://bucket/path/to/image.zarr scales 1,2 - open two multiscale levels of an OME-Zarr from AWS S3
open ngff:https://example.org/image.zarr readAhead 3 - buffer at most three future timepoints
open /path/to/image.zarr labels false - open an image without associated labels
