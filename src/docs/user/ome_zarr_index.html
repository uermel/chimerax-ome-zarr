ChimeraX OME-Zarr plugin

OME-Zarr is a next generation file format specification for storing bioimaging data on the cloud.

This plugin opens OME-Zarr 0.4 (Zarr v2) and OME-Zarr 0.5 (Zarr v3) images in ChimeraX.

Currently supported:

  • YX- and ZYX-order multiscale images with optional leading time and channel axes.
  • OME-Zarr 0.4/Zarr v2 and OME-Zarr 0.5/Zarr v3 storage.
  • Bioformats2raw layout 3 image collections with declared or consecutively numbered series.
  • Opening local or remote zarr files.
  • Identity, scale, and translation transformations in physical units.
  • OMERO channel names, colors, and active state.
  • Opt-in associated OME-Zarr label images as lazy integer index maps.
  • Declared nonzero label values as editable models in ChimeraX's Segmentations tool when labels are requested.
  • Loading specific multiscales as volumes (streamed on demand and cached in memory).
  • Loading all multiscales as a single Volume, accessible using Chimerax's step setting.
  • Adaptive, memory-bounded decoded read-ahead for 3D time-series playback.

Currently not (yet) supported:

  • Plates, collection formats other than bioformats2raw, or multiple multiscales entries.
  • Custom axes or spatial-axis reordering.
  • Non-integer pyramid scaling.
  • Automatic switching between translated levels that do not align to the finest grid.
  •  Commands
    • open  – open local or remote OME-Zarr files
